Tentang JavaScript

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis.

Fitur JavaScript

  • Manipulasi DOM (innerHTML)
  • Event Handling (onclick, onload)
  • Dialog (alert, prompt, confirm)
